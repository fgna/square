# What's New in Square 1.1

Square 1.1 expands the first public source release with new tools for community organizers, improvements to events and learning, and fixes for everyday use on phones and Android.

## Highlights

- **More flexible community setup:** Operators can switch major platform capabilities on or off, including independent controls for the journal, testimonials and recordings. A plugin can serve as the community's start page.
- **Video and audio inside Square:** Admins can upload H.264 MP4 or QuickTime MOV videos for lessons and recordings, add a welcome video, and attach audio or uploaded video to feed posts. Uploaded videos stay on the instance and use expiring playback links.
- **Better events:** Event cover images, recurring-series grouping, highlighted events, easier online-event joining and improved calendar invitations help members find and attend activities. Organizers can edit event proposals and disable day-ahead reminders per event.
- **Learning and courses:** Admins can see course participation and progress. Plugins gain an opt-in task and quiz prototype with saved attempts and adaptive practice support. The task plugin remains experimental.
- **Community communication:** Posts can be pinned, digest emails can use the community's design and preferred sending times, and optional daily journal reminders can be configured.
- **Android support:** Communities can build personalized Android apps and optionally publish an APK download link. The Android app remains experimental and requires separate distribution and acceptance checks.

## Improvements and fixes

The dashboard now shows upcoming events more clearly and counts recurring series once. Mobile dialogs fit smaller screens, lesson selection scrolls into view, and audio can play within lessons. Email greetings use members' first names. Admin analytics link directly to relevant pages.

Fixes also address unexpected session loss during refresh, overly broad login rate limits affecting chat and health checks, event-list ordering and previews, the onboarding wizard obstructing plugin pages, and Android dialogs, downloads and file selection.

## Running and upgrading Square

Square v1.1.0 is a **public source release**. It does not certify production readiness or automatically upgrade an existing community. Operators should review their separate instance configuration, back up their database and uploads, assess the Prisma migrations between their installed revision and v1.1.0, and test the upgrade before deployment.

To try a disposable local demo, follow the [README](../../README.md#try-the-isolated-local-demo). For independent installations, consult the [instance contract](../THIRD-PARTY-INSTANCE-CONTRACT.md) and [deployment boundaries](../DEPLOYMENT-BOUNDARY.md).

See the [v1.1.0 GitHub release](https://github.com/fgna/square/releases/tag/v1.1.0) for the full list of 13 new features, 14 improvements and 10 fixes. The [v1.0.0 overview](v1.0.0.md) describes Square's original foundation.

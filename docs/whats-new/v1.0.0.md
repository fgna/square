# What's New in Square 1.0

Square 1.0 is the first public source release of Square, an open-source platform for independent communities. It brings the core building blocks for running a community together in one customizable web application.

## What you can explore

- **Community conversations:** Member profiles, feed posts, comments and reactions provide a shared place for discussion.
- **Events and learning:** Events, RSVPs, recordings, courses and learning groups support activities beyond the feed.
- **Staying connected:** Messages and notifications help members keep up with community activity.
- **Community operations:** Administration tools, configurable assessments and journal features give organizers additional ways to support members.
- **Extensibility:** Plugin interfaces and example plugins provide a starting point for adapting Square to a community's needs.
- **Language support:** The application includes German and English translations.

The repository also includes a synthetic example content pack for exploring the instance contract. Example content does not represent a live production community.

## Explore Square

Developers can try an **isolated local demo** using the instructions in the [README](../../README.md#try-the-isolated-local-demo). Running it requires a Linux development environment, Docker Engine with Compose v2, Node.js 22, Corepack and curl. The demo uses disposable development credentials and is not intended for production use.

For a separate community installation, start with the [independent instance contract](../THIRD-PARTY-INSTANCE-CONTRACT.md) and [deployment boundaries](../DEPLOYMENT-BOUNDARY.md). Some features require additional configuration or external services.

## Release status

**Square v1.0.0 is a public source release, not a production-readiness certification.** Complete fresh-install end-to-end acceptance is still a separate milestone. Review deployment, data and security requirements before operating a real community.

See the [v1.0.0 GitHub release](https://github.com/fgna/square/releases/tag/v1.0.0) for the release artifact and technical context.
